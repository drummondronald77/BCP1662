1662 BCP DAILY OFFICE — WEB/PWA

This is a static Progressive Web App. Upload the contents of this folder to any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.). Then open the URL on your phone.

ANDROID (Chrome): open the site → menu (⋮) → Add to Home screen / Install app.
iPHONE (Safari): open the site → Share → Add to Home Screen.

The included manifest and 192/512 icons make the installed shortcut appear as an app icon. The service worker caches the app shell for offline use after the first visit.

Content note: this web build carries over the v5 1662 civil-calendar lectionary references, 30-day Psalm appointments, Daily Office structure, and Litany. Like v5, it does not bundle the full KJVA or complete Coverdale Psalter corpus; those appointed references remain visible.
